# Slow Walker

Slow Walker is a minimal Minecraft Paper plugin that slows down every player's walking speed to a fixed, very slow pace as soon as they join the server. It requires no configuration and works automatically, making it ideal for roleplay, challenge maps, or servers that want to encourage a more deliberate pace. The plugin sets each player's base movement speed attribute to 0.05 (roughly one-seventh of the default speed), overriding sprinting and walking. Players can still jump, interact, and perform other actions, but their movement across the ground is dramatically reduced.

## Install

1. Download the `SlowWalk-1.0.0.jar` file from the releases section.
2. Stop your Minecraft server.
3. Place the `.jar` file into the `plugins` folder of your server directory.
4. Restart your server.

## Use

1. Ensure the plugin is loaded by checking the server console for the message "SlowWalk enabled.".
2. Have any player join the server.
3. Observe that the player's movement speed is now set to a very slow pace.
4. No commands or permissions are needed; the plugin works automatically for all players.
5. To disable the effect, remove the `.jar` file from the `plugins` folder and restart your server.
